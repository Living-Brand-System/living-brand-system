# Layouts 출처

이미지는 `guideline_assets/web/layouts/`, 제작 규칙 SVG는 `guideline_assets/layouts/*/construction/`에서 그대로 복사했습니다.
`metadata/cms-assets.json`의 related_asset_id에 따라 Type A 4개·B 9개·C 3개를 연결했습니다.

Off는 적용 이미지, On은 원본 제작 규칙 SVG 전체를 위에 겹쳐 보여줍니다. 사용자가 정합 여부와 무관한 중첩을 승인했으므로 정밀 좌표를 보정하지 않습니다. SVG 내부 문자·로고·면·원본 선도 함께 표시되며, 신규로 그리는 1px 가이드 오버레이와는 구분합니다.

# Typography 에셋 출처

모든 파일은 전달된 `guideline_assets/`에서 가져왔습니다. 원본은 변경하지 않았습니다.

- `typeface-korean.png`, `typeface-english.png`: `guidelines/hd-hyundai-cxd-guidelines.pdf` 33쪽 문자 표본.
- `micro-bold.png`, `micro-medium.png`, `micro-light.png`: 같은 PDF 35쪽 국·영문 혼용 조판 예시. 원본 가이드선을 포함합니다.
- `incorrect-01.png`~`incorrect-06.png`: 같은 PDF 40쪽 사용 금지 사례, 번호 순서 유지. 테두리·라벨·설명은 제외하고 도판만 추출했습니다.
- PDF 파생 PNG는 144dpi·투명 배경으로 렌더링했습니다. 글자나 도형을 수정하지 않았습니다.
- `usecase-banner.webp`: `web/applications/offline-banner/vertical/application-offline-banner-vertical-01.webp`.
- `usecase-poster.webp`: `web/applications/poster/examples/application-poster-example-46.webp`.
- `usecase-presentation.webp`: `web/applications/presentation/cover/application-presentation-cover-01.webp`.

마지막 세 파일은 그대로 복사했습니다. Figma의 Signage·Debit Card를 재현한 것이 아니라 제공 에셋 안에서 선정한 적용 사례입니다.

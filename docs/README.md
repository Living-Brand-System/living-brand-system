| 그룹 | 역할 |
| --- | --- |
| [Features](features/README.md) | 기능 역할별 코어 계약(입력·출력)과 노출 표면 |
| [Surfaces](surfaces/README.md) | 전달 채널(Page·AI Chat·Slack·REST)이 기능을 노출하는 방법 |

## 2. 작성 규칙

- H1은 `번호. 한국어 문서명` 형식으로 씁니다.
- H2는 `번호. 한국어 섹션명` 형식으로 씁니다.
- H3부터는 단순 섹션 순번을 붙이지 않습니다. 단, 유즈케이스 ID나 구현 단계명처럼 의미 있는 식별자는 유지할 수 있습니다.
- 같은 레벨의 헤더는 같은 문장 패턴을 사용합니다.
- 문서 본문은 한국어를 기본으로 쓰되, 제품 역할명과 System 용어는 필요한 경우 English term을 유지합니다.
- 컬렉션, API, DB 필드처럼 구현 세부사항은 합의 전까지 개념 문서에 넣지 않습니다.
